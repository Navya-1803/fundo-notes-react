## fundo-notes-react

 A React.js application developed incrementally through multiple Use Cases (UC1-UC7). Each use case is implemented in a separate Git branch to demonstrate the progressive development of the application.

 ## Project Overview

 The Fundo Notes App is used to creating, updating, archiving and deleting notes.

 This is a frontend project.

 ## Branch Structure

| Branch | Description |
|---|---|
| main | Default/main branch of the repository |
| develop | Contains the initial React project structure and integrated development changes |
| feature/UC1-app-structure | Sets up the initial Fundo Notes application structure with reusable Header, Sidebar, and MainContent components |
| feature/UC2-sidebar-navigation | Adds reusable sidebar navigation for Notes, Archive, and Trash sections |
| feature/UC3-create-note-ui | Adds the user interface for creating notes with title, description, and Add Note button |
| feature/UC4-add-note-functionality | Adds functionality to create and display notes using React state |
| feature/UC5-delete-note | Adds functionality to delete existing notes |
| feature/UC6-edit-note | Adds functionality to edit and update existing notes |
| feature/UC7-archive-note | Adds functionality to archive, restore, edit, and delete notes through the Archive section |
